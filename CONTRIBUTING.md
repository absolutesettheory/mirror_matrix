# Contributing

Thank you for your interest in improving this project.

This repository is currently organized as a research artifact and documentation bundle. Contributions are most valuable when they improve:

- documentation clarity,
- artifact organization,
- metadata and provenance,
- accessibility of the project materials,
- accurate descriptions of the research content.

## Ways to contribute

You may contribute by:

- improving the README and project documentation,
- clarifying the project overview,
- adding missing references or context,
- improving artifact naming and organization,
- proposing a clearer directory structure,
- adding reproducibility notes or annex material.

## Best practices

- Keep documentation factual and concise.
- Prefer clear, explicit language over speculation.
- Include references when adding technical or academic context.
- Maintain a clear distinction between “artifact” and “future implementation.”
- If code is added later, document how it relates to the PDF/report.

## Suggested workflow

1. Fork the repository.
2. Create a feature branch.
3. Update the relevant docs and metadata.
4. Submit a pull request with a clear summary of the change.

## Reporting issues

Use the GitHub issue tracker to report:

- broken links,
- unclear documentation,
- naming inconsistencies,
- missing context or references,
- requests for additional project information.

## Code of conduct

Please be respectful, constructive, and evidence-based in all discussions.
